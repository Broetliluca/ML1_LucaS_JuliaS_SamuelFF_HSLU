Heart Disease Risk Prediction — Group Project (HSLU ML1)

This repository contains the group project for the Master’s Program in Applied Information and Data Science at HSLU in the module *Applied Machine Learning & Predictive Modelling 1*.  
The project focuses on predicting self-reported heart attack risk based on demographic, lifestyle, and health survey data.

Repository Structure
--------------------
report-v7.Rmd     — Main analysis report (R Markdown)
report-v7.html    — Rendered HTML output of the report
report-v7_cache/  — Internal cache generated by knitr
report-v7_files/  — Supporting files (figures, assets) generated by knitr

Data Source
-----------
Dataset used in this project (2022 BRFSS extract):  
https://www.kaggle.com/datasets/kamilpytlak/personal-key-indicators-of-heart-disease

The dataset originates from the Behavioral Risk Factor Surveillance System (BRFSS), conducted by the U.S. CDC.

Running the Report
------------------
To reproduce the analysis:

1. Open `report-v7.Rmd` in *RStudio*
2. Ensure required R packages are installed
3. Render via:
   - `Knit → Knit to HTML`
   - Or from R console:
     ```r
     rmarkdown::render("report-v7.Rmd")
     ```

The knitting process automatically generates:
- report-v7.html
- report-v7_cache/
- report-v7_files/

Note: Do not manually edit or version-control cache artifacts unless needed for reproducibility.

Project Objective
-----------------
The goal of the project is to:
- Analyze structured health survey data,
- Train ML models for heart attack prediction,
- Compare predictive performance (GLM, GAM, SVM, NN),
- Interpret predictors in a non-clinical context, and
- Discuss model thresholding behavior under class imbalance.
